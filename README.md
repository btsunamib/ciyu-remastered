# 词屿 · 重制版

安静、顺手的词汇练习空间。认读、听力、口语、写作分别记录进度，间隔复习负责长期巩固。

**旧版仓库**：https://github.com/btsunamib/word-test-2  
**新版仓库**：https://github.com/btsunamib/ciyu-remastered

## 开始使用

安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
npm run dev
```

访问 `http://localhost:8080`。项目没有运行时依赖，不需要 `npm install`。也可以用 `python -m http.server 8080` 或其他静态服务器。

GitHub Pages：在仓库 Settings → Pages 中选择 Deploy from a branch → main → / (root)。

## AI 学习与个性化（2026-10-04）

设置中的 **AI 学习助手默认关闭**。开启后填写 API 地址和密钥，从服务的 `/models` 列表直接选择模型，支持 OpenAI Chat Completions 格式的服务。可选 OpenAI / DeepSeek 预设，也可填写自己的兼容服务；网页直连服务，需要服务允许 CORS。填写密钥、切换地址和打开设置时自动获取模型，也可以手动刷新。完整 `/chat/completions` 地址会自动推导出同级 `/models` 地址。列表包含服务返回的模型，请按用途选择对话模型；图片识别需视觉模型。

- 学习卡片上为当前词造句、用当前词与同书其他词编小故事、围绕本词问答。听写与中译英题先作答，再显示 AI 入口，避免提前泄露答案。
- AI 学习页从任意词书选择 1–10 个单词或完整词组，支持搜索、随机挑词、故事方向、A2–C1 难度、双语例句、小故事和多轮问答。
- 英文例句和故事可朗读、复制，目标表达突出显示。生成内容自动保存为学习素材，包含在完整词书备份中；问答仅保留在当前页面会话。
- 上传或拖入 TXT、Markdown、CSV、TSV、含文字的 PDF、Word `.docx`，也可直接粘贴文字。AI 提取英文和完整词组、补全中文释义、按主题命名并自动创建新词书。长文档逐段整理，不截掉后半部分；可取消，失败时不会创建半本词书。最大文件 15 MB、15 万字符、PDF 200 页。扫描 PDF 需先识别为文字，旧版 `.doc` 需另存为 `.docx`。
- PDF / Word 读取器按需从 jsDelivr 加载 PDF.js 4.10.38 和 Mammoth 1.11.0，仅提取文字；原始文件不会发送给音源或读取器 CDN。只有点击创建时才把文字发送到用户选择的 AI 服务。
- API 密钥单独保存在当前浏览器会话，可勾选在本机记住。密钥不进入词书或外观备份，不提交到仓库，不经过词屿服务器。启用 AI 本身不会自动发起付费模型请求。

外观提供鸢尾、林间、暖沙、玫瑰、海盐、葡萄 6 套浅深配色，并支持分别设置强调色、页面背景、卡片颜色和文字颜色。可调整字体风格、字号 85–125%、圆角、360–820px 学习卡片宽度、舒适/紧凑留白、桌面/平板顶部或侧边导航、动画，以及原有自定义背景。外观方案可单独导入/导出。

学习卡片默认宽 580px，基础高度约 235px，手机按屏幕宽度适配。例句、翻译和故事让卡片自然增高，页面正常滚动。平板默认禁止页面长按选择文字和系统触摸浮层，保留输入框文字选择；可在外观设置中开启长按选词。键盘焦点提示仍保留。

网站缓存版本已更新；已打开的旧页面刷新后会安装新缓存，再刷新即可使用新界面，词书与学习进度保持。

## 枫叶模式 · LAP

导航中的 **枫叶模式** 提供独立的 **LAP 单词模式（AI）**，并预留 Vocab 等未来模式。JSON 导入、词族查看与词形练习无需 AI；文档/图片识别、改错题生成及造句/改错批改需在设置中开启 AI、填写密钥并选择模型。

- **JSON 直接导入（无需 AI）**：上传 `.json` 文件或粘贴 JSON 数组，使用 `word`、`pos`、`noun`、`verb`、`pastTense`、`adjective`、`adverb` 字段，可选 `num`、`meaning`、`note`。`N/A`、空白或缺省字段表示没有对应形式，`/` 分隔多个词形，过去式独立成列。括号说明及星号保存在备注；不改原文拼写，不联网补词或补释义。缺少释义仍可保存，并在核对页手动补充；格式或词形错误显示行号，失败不保存部分数据。全部字段、词形和备注随完整备份保留。
- 上传一份 TXT / Markdown / CSV / TSV / 含文字 PDF / Word `.docx`，或最多 8 张 PNG / JPEG / WebP 图片，也可以粘贴带列标题的词表。单文件最多 15 MB，合计 30 MB。扫描资料请上传为图片。长文档逐段整理，多张图片逐张识别，最后合并同一主词的词族；识别失败或取消不保存半份结果。
- AI 保留资料中列出的词形与词性，补全中文释义，不能擅自添加表中没有的派生词。识别后先核对主词、含义、各词性形式和备注，可移除误识别行。同格多个形式用 `/` 分隔；空白和斜线代表没有对应形式。支持常见名词、动词、形容词、副词及其他词性列。
- 词族表可搜索、分页、朗读和编辑。背诵只填写词性形式，同格多个正确词形任选一个，不考过去式；答错会隔几个项目再次练习，答对后按 1、3、7、15、30 天安排复习。反馈后手动继续，刷新可恢复。
- 模拟卷默认三类各 3 题：听音转换（每词读两遍，支持手动重听）、按随机指定词性造句、句子改错。不考释义和过去式。听音题只从至少有 3 种词性的词族出题（过去式不算一种词性），缺失格用斜线封闭；同格填写任意一个正确词形得该格 1 分。其余每题 2 分。
- 造句需要词性正确且通过情境体现含义，单纯提到“老师教我这个词”等句子为 0 分。改错随机包含主谓一致、冠词、介词或 LAP 词性问题，答题时不展示类型、位置或参考答案。AI 批改接受合理的其他改法，返回逐题得分、解释和参考。
- 每类题数可设 0–20，可以选择是否允许词族在卷内重复。默认禁止重复；即使允许重复，也优先选择未出现的词族。数量不足会明确提示调整，不会悄悄复用不合格词族。生成时自动尝试依次播放听写；浏览器限制自动发音时可手动播放。
- 试卷可打印，作答自动保存，交卷成功后锁定本卷，可再生成一张继续练习。生成/批改可取消，失败保留答案，可重新批改。每份 LAP 保留最近 20 张试卷。LAP 词族、独立背诵进度、未完成作答和批改结果都包含在完整 JSON 备份里；原始文档和图片、API 密钥不进入备份。

验证：43 项 Node.js 测试通过，并使用 Chromium 和模拟 AI 接口检查模型下拉选择、导入核对、出卷、两次发音、刷新恢复、批改失败重试与手机布局。未使用真实密钥调用付费 AI，模型识别与评分质量取决于所选服务。

## 原有学习方式

| 模式 | 练习与掌握规则 |
| --- | --- |
| 认读 | 看英文判断认识与否，连续认识 3 次掌握，可调 2–5 次；答错或“记错了”清零。 |
| 听力 | 听写正确 1 次，加听音连续认识 2 次；听写答错不清零听音连对。 |
| 口语 | 看中文回忆英文、看英文回忆中文，各自评说对 2 次。没有录音或自动语音评分。 |
| 写作 | 看中文写英文，要求写全同义表达集合；累计写对 2 次，写错不清零。 |
| 拼写审查 | 全书每词只考一次，包含已掌握词；拼对计为听力掌握，拼错标为未掌握并记录错词，然后继续。 |
| 记忆复习 | 复习单书或全书的到期词，默认阶段为 20 分钟、1 小时、9 小时、1、2、4、7、15、30 天；答错回退、再次出现。 |

**所有模式都手动继续。** 答对后不会计时跳题；口语自评后也不会自动进入下一题。反馈页刷新后仍可继续核对答案。只有点击“确认，继续”或使用相应快捷键，才进入下一项。

同时练习默认 12 个词，可调 5–30 个；掌握一个补入一个。认读、听力、口语默认答对间隔 7 词、答错间隔 3 词，词不足时自动缩短。写作间隔固定为答对 2 词、答错 1 词。可以开关认读的旧词随机回访，默认每掌握 5 个新词插入 2 个旧词。

## 英语发音

英语使用独立 MP3 音频，不调用浏览器 `speechSynthesis`。默认音源是有道词典发音：

```text
https://dict.youdao.com/dictvoice?audio={text}&type={accent}
```

英音 `type=1`、美音 `type=2`。界面提供口音切换、试听、0.6–1.3 倍速和重复播放；预加载下一组发音以减少等待。提供方可能改变公共音频接口，设置中可换成自己的 HTTPS 音频链接模板，无需更改代码。仅中文朗读保留系统语音引擎与中文发音人选择。

本次验证确认单词、词组、整句请求返回 `audio/mpeg`。这不是带可用性保证的正式商业 API。音频请求会把要朗读的英文发送给选择的音源服务；词书全文和学习进度不会上传。

页面可离线使用。英语首次播放需要网络，Service Worker 尝试缓存最近 24 段有道音频；成功缓存的音频可离线播放。浏览器不支持缓存、提供方错误或切换口音后的新音频仍需要网络，不会悄悄改回浏览器英文声音。可以单独清除英语音频缓存。

## 词书与词表

- 新建、重命名、追加导入、删除词书；单模式重新练习和全书重置。
- 粘贴文字或选择/拖入 TXT；识别 UTF-8、GB18030、UTF-16LE/BE。
- 支持音标、多释义、同义表达、注释行、重复合并、导入预览与错误行提示。
- 词表搜索英文/中文；按四种模式筛选掌握状态；筛选审查错词。
- 隐藏英文或中文、逐词揭晓、打乱顺序、恢复原序；每词播放英语发音。
- 编辑英文/音标/释义、删除词条；单独调整某模式或统一调整四模式掌握状态。
- 导出单书 TXT；导出/恢复包括未完成练习的完整 JSON 备份。
- 分页展示大词表，避免一次渲染数千个词条。

同义英文在认读/听力/口语中分别考，在写作中按组考。重新导入同组表达会重新合并分组，避免同义答案被分散。编辑或删除词条会结束本书未完成练习，已掌握的其他词保持进度，避免继续考已删除的内容。

## 数据与旧版迁移

新版使用 `localStorage` 键 `ciyu.remastered.v2`，旧版键为 `ciyu.vocab.v1`。同域名、同浏览器首次打开新版时，自动读取并迁移旧词书、四种掌握状态、复习计划、设置以及未完成练习的计数。**不修改或删除旧版数据。** GitHub Pages 同账号不同仓库路径共享同一网站域名，因此可自动迁移。

如果旧版是本地文件或在另一域名，设置中的“迁移旧版数据”提供旧版导出代码，将旧版 JSON 导入新版即可。备份支持旧版和新版结构。清空新版后保持一个空的新版本，避免再次自动导入旧版。

每本词书、每种模式的练习断点独立保存，切换词书也不会丢掉另一份进度。没有服务器账号或云端同步。清除浏览器站点数据会删除本地内容，可以先导出备份。

- 认读/听音/复习：`1` / `←` 不认识，`2` / `→` 认识。

- 反馈页：`Enter`、`空格` 或 `→` 手动继续；符合条件时 `1` / `←` 改判。
- 输入框中的空格和数字始终正常输入，不触发全局快捷键。

## 沉浸考试、词性背诵和每日目标（2026-10-05）

- 模拟卷可选全屏沉浸式，也可在卷首进入或退出；浏览器限制原生全屏时仍有隐藏导航的沉浸界面。题目使用英文；听写转换题合并为一张多行表，手机按表格行展开成两列填空，不横向溢出。
- 背诵只练词性形式，排除过去式。已有词表中的过去式保留在词族表和备份中，背诵及新模拟卷都不考。Enter 移动到下一格，最后一格检查；模拟卷最后一个答案的 Enter 直接交卷。Shift+Enter 在长答案中换行，中文输入法组合期间不会提交。
- 检查结果显示在每个空：正确为绿色，错误为红框；悬停、点击或键盘聚焦显示绿色正确答案。背诵反馈刷新仍可恢复。
- 主页显示累计和今日实际练习的去重单词数，普通词书与 LAP 合并统计。每日目标可设 1–1000。历史已掌握词计入累计，新的逐词练习日期从更新起记录；导入不计作学习。
- 设置可选流式输出及思考/不思考/跟随模型。支持按 DeepSeek、Qwen 与 OpenAI 格式发送思考开关；固定思考模型未必支持完全关闭，可在接口兼容选项中调整。首个正文或思考 token 前保留 90 秒等待上限，收到 token 后取消此超时，仍可手动取消。流式问答实时显示正文，材料显示生成预览；模拟卷生成只显示接收进度，不泄露答案。连接中断和截断不会保存半份材料。

## 考试与多词形规则（2026-10-06）

- 新模拟卷只含词性转换、造句和改错，默认各 3 题；不出单词释义题，过去式不计入听写列、分数或三个词性的资格。改错不出时态题，也不向生成接口提供过去式列。
- 造句题从当前词族已有的词性中随机抽选，再随机选择该词性已有的一个词形。题面同时显示英文词形与词性，批改要求按指定词性造句，过去式不参与抽选。
- 背诵和新模拟卷同一词性有多个正确词形时，任选一个即可；大小写、分隔方式不影响判断，空白或夹带错误词仍判错。
- 已保存的未提交试卷自动移除释义题、过去式填空及旧时态改错题，保留其他答案。已提交旧试卷作为历史记录保留原题目和原分数，不改写已完成的成绩。

## 闪卡旁的 AI 对话（2026-10-07）

记忆卡片上的“问问 AI”会打开当前卡片旁的聊天气泡，不跳转页面，也不改变作答、进度或闪卡内容。桌面优先放在卡片右侧或左侧；手机和平板采用屏幕内的浮动窗口，并随可视区域变化调整尺寸。

- 对话自动带上当前词汇及释义，可连续追问，兼容流式、思考模式和普通回复；发送时不显示隐藏的听写/拼写答案。
- Enter 发送，Shift+Enter 换行，Esc 或关闭按钮收起并停止正在进行的回复；支持手动停止、清空和失败后重发。聊天框内的快捷键不会给闪卡判分或跳题。
- 同一页面会话内，各词分别保留对话和草稿，关闭重开可继续；换词时收起对话并停止旧请求，离开练习时也会收起。对话暂存在内存，刷新后清空，不进入词书备份。
