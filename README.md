# 词屿 · 重制版

安静、顺手的词汇练习空间。认读、听力、口语、写作分别记录进度，间隔复习负责长期巩固。

**旧版仓库**：https://github.com/btsunamib/word-test-2  
**新版仓库**：https://github.com/btsunamib/ciyu-remastered

## 开始使用

安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
npm run dev
```

访问 `http://localhost:8080`。项目没有运行时依赖，不需要 `npm install`。也可以用 `python -m http.server 8080` 或其他静态服务器。

GitHub Pages：在仓库 Settings → Pages 中选择 Deploy from a branch → main → / (root)。

## 学习方式

| 模式 | 练习与掌握规则 |
| --- | --- |
| 认读 | 看英文判断认识与否，连续认识 3 次掌握，可调 2–5 次；答错或“记错了”清零。 |
| 听力 | 听写正确 1 次，加听音连续认识 2 次；听写答错不清零听音连对。 |
| 口语 | 看中文回忆英文、看英文回忆中文，各自评说对 2 次。没有录音或自动语音评分。 |
| 写作 | 看中文写英文，要求写全同义表达集合；累计写对 2 次，写错不清零。 |
| 拼写审查 | 全书每词只考一次，包含已掌握词；拼对计为听力掌握，拼错标为未掌握并记录错词，然后继续。 |
| 记忆复习 | 复习单书或全书的到期词，默认阶段为 20 分钟、1 小时、9 小时、1、2、4、7、15、30 天；答错回退、再次出现。 |

**所有模式都手动继续。** 答对后不会计时跳题；口语自评后也不会自动进入下一题。反馈页刷新后仍可继续核对答案。只有点击“确认，继续”或使用相应快捷键，才进入下一项。

同时练习默认 12 个词，可调 5–30 个；掌握一个补入一个。认读、听力、口语默认答对间隔 7 词、答错间隔 3 词，词不足时自动缩短。写作间隔固定为答对 2 词、答错 1 词。可以开关认读的旧词随机回访，默认每掌握 5 个新词插入 2 个旧词。

## 英语发音

英语使用独立 MP3 音频，不调用浏览器 `speechSynthesis`。默认音源是有道词典发音：

```text
https://dict.youdao.com/dictvoice?audio={text}&type={accent}
```

英音 `type=1`、美音 `type=2`。界面提供口音切换、试听、0.6–1.3 倍速和重复播放；预加载下一组发音以减少等待。提供方可能改变公共音频接口，设置中可换成自己的 HTTPS 音频链接模板，无需更改代码。仅中文朗读保留系统语音引擎与中文发音人选择。

本次验证确认单词、词组、整句请求返回 `audio/mpeg`。这不是带可用性保证的正式商业 API。音频请求会把要朗读的英文发送给选择的音源服务；词书全文和学习进度不会上传。

页面可离线使用。英语首次播放需要网络，Service Worker 尝试缓存最近 24 段有道音频；成功缓存的音频可离线播放。浏览器不支持缓存、提供方错误或切换口音后的新音频仍需要网络，不会悄悄改回浏览器英文声音。可以单独清除英语音频缓存。

## 词书与词表

- 新建、重命名、追加导入、删除词书；单模式重新练习和全书重置。
- 粘贴文字或选择/拖入 TXT；识别 UTF-8、GB18030、UTF-16LE/BE。
- 支持音标、多释义、同义表达、注释行、重复合并、导入预览与错误行提示。
- 词表搜索英文/中文；按四种模式筛选掌握状态；筛选审查错词。
- 隐藏英文或中文、逐词揭晓、打乱顺序、恢复原序；每词播放英语发音。
- 编辑英文/音标/释义、删除词条；单独调整某模式或统一调整四模式掌握状态。
- 导出单书 TXT；导出/恢复包括未完成练习的完整 JSON 备份。
- 分页展示大词表，避免一次渲染数千个词条。

同义英文在认读/听力/口语中分别考，在写作中按组考。重新导入同组表达会重新合并分组，避免同义答案被分散。编辑或删除词条会结束本书未完成练习，已掌握的其他词保持进度，避免继续考已删除的内容。

## 数据与旧版迁移

新版使用 `localStorage` 键 `ciyu.remastered.v2`，旧版键为 `ciyu.vocab.v1`。同域名、同浏览器首次打开新版时，自动读取并迁移旧词书、四种掌握状态、复习计划、设置以及未完成练习的计数。**不修改或删除旧版数据。** GitHub Pages 同账号不同仓库路径共享同一网站域名，因此可自动迁移。

如果旧版是本地文件或在另一域名，设置中的“迁移旧版数据”提供旧版导出代码，将旧版 JSON 导入新版即可。备份支持旧版和新版结构。清空新版后保持一个空的新版本，避免再次自动导入旧版。

每本词书、每种模式的练习断点独立保存，切换词书也不会丢掉另一份进度。没有服务器账号或云端同步。清除浏览器站点数据会删除本地内容，可以先导出备份。

## 体验与快捷键

- 书库一键选择六种练习，专注页面只呈现当前题和必要操作。
- 响应式桌面/手机布局、触控按钮、输入框自动聚焦、分页词表。
- 浅色/深色/跟随系统主题，上传背景后自动压缩与柔化。
- 答题反馈与完成彩带；尊重系统“减少动态效果”设置。
- 认读/听音/复习：`1` / `←` 不认识，`2` / `→` 认识。
- 口语：`空格` / `Enter` 揭晓，`1` 说对了，`2` 没说出来。
- 输入题：`Enter` 检查，写作 `Shift+Enter` 可换行。
- 反馈页：`Enter`、`空格` 或 `→` 手动继续；符合条件时 `1` / `←` 改判。
- 输入框中的空格和数字始终正常输入，不触发全局快捷键。

## 开发与验证

```sh
npm test
npm run build
```

`build` 将网站文件复制到 `dist/`，可以部署到任意静态托管服务。测试使用 Node.js 内置测试器，不需要第三方依赖。

```text
index.html          页面外壳
style.css           响应式布局与主题
core.js          导入、调度、掌握规则、复习与迁移
storage.js       本地存储、备份恢复
audio.js         独立英语音频与中文朗读
app.js           页面渲染与交互
icons.js         SVG 图标
sw.js               离线页面与有界音频缓存
core.test.js        核心行为测试
responsive.html     响应式检查页面
serve.mjs           零依赖开发服务器
build.mjs           静态打包
```
